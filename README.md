# Φυσική Γ' Γυμνασίου — Σημειώσεις & Ασκήσεις

Σημειώσεις και διαδραστικές ασκήσεις ανά κεφάλαιο, για μαθήματα Φυσικής Γ' Γυμνασίου.

Κάθε κεφάλαιο ζει στον δικό του φάκελο (`kefalaio-0/`, `kefalaio-1/`, `kefalaio-2/`, ...) ως αυτόνομη στατική σελίδα.

Το **Κεφάλαιο 0** («Έργο, Ενέργεια και Ισχύς») δεν ανήκει στην ύλη της Γ' Γυμνασίου — είναι προαπαιτούμενη ύλη από τη Β' Γυμνασίου (Κεφάλαιο 5 «Ενέργεια») που χρειάζεται να καλυφθεί πρώτα.
